# Junior Programming Language

Junior es un lenguaje de programación experimental desarrollado
como proyecto académico para la materia de Lenguajes y Autómatas II.

El proyecto tiene como objetivo diseñar e implementar un lenguaje
de programación propio, utilizando herramientas para el análisis
léxico y sintáctico.

## Tecnologías utilizadas

- Java
- ANTLR4
- Apache Maven

## Características del lenguaje

Junior utilizará la extensión `.jr` para identificar sus
archivos de código fuente.

Entre las funcionalidades que se planea desarrollar se encuentran:

- Definición de una gramática propia.
- Análisis léxico (Lexer).
- Análisis sintáctico (Parser).
- Validación de instrucciones.
- Generación de árboles de análisis sintáctico.
- Detección y manejo de errores.

## Estructura del proyecto

El proyecto utiliza una estructura basada en Apache Maven,
con integración de ANTLR4 para el procesamiento de gramáticas.

## Estado del desarrollo

En desarrollo.

Junior se encuentra en sus primeras etapas de implementación.

Las características y la sintaxis del lenguaje podrán
evolucionar durante el desarrollo del proyecto.

## Objetivo académico

Aplicar los conocimientos adquiridos en la materia
de Lenguajes y Autómatas II mediante el diseño
e implementación de un lenguaje de programación propio.
